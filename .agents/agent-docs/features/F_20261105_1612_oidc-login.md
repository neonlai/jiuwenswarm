# Web 通道 OpenID Connect 登录

## 关联依据

- 设计：无独立 D。任务要求在本 fork 增加可配置的 OIDC 授权码登录，未配置时保持原行为。
- spec：[S_01_oidc-login](../specs/jiuwenswarm/common/auth/S_01_oidc-login.md)。
- 日期：2026-11-05。
- 实际实施范围：`jiuwenswarm-web` 上的通用 OIDC 登录、会话 Cookie、向已有 `X-User-Token` 的透传，以及默认关闭的 RFC 8693 换票函数。未连接真实 ADFS，也没有把换票接到工具调用。

## 决策归属与关系

仓库里已有的用户登录是网关侧华为账号 Account Kit，前端企业版另走管理端 IdP。本次不改这两条路径。OIDC 作为 Web 静态服务上的独立入口，只有配置齐全才出现。

没有可续写的 OIDC 决策记录，因此新建本 feature 与 `S_01`。

## 实际实现与开发决策

- 配置来自环境变量，其次才是 `config.yaml` 的 `oidc` 段。签发方、客户端 ID、回调地址缺一则不开启。显式 `enabled=false` 强制关闭。这样默认安装和未设置变量的本地启动不访问 IdP。
- 授权端点与令牌端点只从 `{issuer}/.well-known/openid-configuration` 读取，以便 ADFS 使用其 `/adfs/oauth2/` 路径。PKCE S256 默认开启，旧场站可关掉。密钥用 `client_secret_post`，不放进授权 URL。
- `state` 存在服务端，并用 HttpOnly Cookie 绑到发起登录的浏览器。回调核对两边，用过即删。`nonce` 写入 ID 令牌并在验签后比对。
- 会话 Cookie 只放身份声明。访问令牌留在 Web 进程内存，供代理补 `X-User-Token`。进程重启后令牌消失，身份 Cookie 在过期前仍有效，但下游令牌需要重新登录。注销会作废会话标识。
- 图标栏按钮只在状态接口报告 `enabled` 时渲染。未配置时该请求由 Web 服务直接回答，不改变华为账号路由。
- `exchange_on_behalf_of` 是 RFC 8693 钩子，默认不发请求，工具也不调用。ADFS 的 on-behalf-of（`requested_token_use`）留作后续。

## 与设计的偏差

无独立设计文档。相对任务说明：登录做在 `jiuwenswarm-web` 而不是外部 `agent-gateway` 包，因为网关源码不在本 fork。`npm run dev` 把 `/api` 直接转到网关，因此这条开发命令上看不到 OIDC 路由；`make start-debug` 的 web 进程可以。

### 可见行为、副作用与证据有效范围

测试替身返回 ADFS 风格的发现文档（`/adfs/oauth2/authorize` 与 `/token`）、JWKS 和 ID 令牌。断言覆盖：未配置与模板默认值不开启；授权 URL 含 PKCE 且不含密钥；state 缺失与重放被拒绝；错误 nonce 与坏签名被拒绝；回跳拒绝外站地址；注销后 `X-User-Token` 不再给出；`required` 在未配置时不拦截、配置后匿名文档请求 302；OBO 默认不访问网络，开启后表单为 RFC 8693 且不含 `requested_token_use`。

证据只覆盖这次源码和该替身。换签名算法、多进程会话存储或真实 ADFS 时钟与声明集时需要重测。

## 验证结论

- 已证明范围：配置门闩、授权码与 PKCE 的请求形状、回调 state/nonce、RS256 验签失败、会话与注销、必选门闩、OBO 默认关闭。
- 未覆盖：真实 ADFS、浏览器点击、`npm run dev` 直连网关、多进程共享会话。
- 可支持的交付判断：代码与配置层满足“未配置保持原行为、配置后登录路径可被测试替身走通”。不能声称已对 Neon 的 ADFS 联调通过。

## 已知遗留

| 遗留项 | 未处理原因 / 性质 | 影响与现有处置 | 后续入口 / 条件及所需验证 |
| --- | --- | --- | --- |
| ADFS on-behalf-of（`requested_token_use`） | 任务明确不作为本次完成条件 | 用户访问令牌只通过已有 `X-User-Token` 原样传递；RFC 8693 函数默认关闭 | 有下游资源标识和 ADFS 换票样本后再接工具路径 |
| 访问令牌只在单个 Web 进程内存 | 避免把令牌写入 Cookie 或仓库 | 进程重启后下游令牌消失，用户需重新登录 | 多副本部署时再做共享存储 |
